# Code of Conduct

We want Zelmoriq to be a friendly, harassment-free space for everyone, whatever their experience, background or identity.

**Expected behaviour**
- Be respectful and patient, especially with beginners
- Give and accept constructive feedback gracefully
- Focus on what is best for the project and its users

**Unacceptable behaviour**
- Harassment, insults, discrimination or personal attacks
- Publishing other people's private information
- Spam, trolling, or sexual or violent content

Maintainers may remove comments, commits or contributors that break these rules. Report problems to the maintainers through a private GitHub security advisory or the contact address on the repository profile. This code is adapted from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org).
